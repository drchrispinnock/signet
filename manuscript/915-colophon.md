# Colophon

Although the Signet wallet was written wholly with AI tools, this book was not. I wrote the text. However, the job was easier than other writing jobs because I knew the application inside out.

I started writing this book with Zed, but ended up vibe-coding an application to edit markdown files, called Markup. The manuscript files are writing in markdown and live in the Signet git repository. Markup handled the bibliography. Two special branches are used with Leanpub to preview and publish the book.

I asked Claude and ChatGPT to check the book for mistakes, which they inevitably found. However, writing the book gave me the opportunity to test Signet throughly from a user's perspective. I found some things that the AI didn't quite get right.
