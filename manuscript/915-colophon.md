# Colophon

Although the Signet wallet was written wholly with AI tools, this book was not. I wrote the text. However, writing it was easier than usual because I knew the application inside out.

I started writing this book with the [Zed editor](https://zed.dev), but ended up [vibe coding](https://en.wikipedia.org/wiki/Vibe_coding) an application to edit Markdown files, called [Markup](https://github.com/drchrispinnock/markup). The manuscript files are written in Markdown and live in the Signet git repository. Markup handled the bibliography. Two branches fed [Leanpub](https://leanpub.com)'s preview and publish builds in both PDF and EPUB.

I asked [Claude](https://claude.ai) and [ChatGPT](https://chatgpt.com) to check the book for mistakes, which they inevitably found. Writing the book gave me the opportunity to test Signet thoroughly from a user's perspective. AI tools don't always get it right, but neither do humans.
