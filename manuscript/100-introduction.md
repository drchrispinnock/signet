## Other Wallets

There are other wallets for Tezos and I encourage you to try them out. Wallet software is a matter of personal preference. For example, Signet is a desktop wallet and you might prefer to work on your mobile. Here is an overview of the some other wallets that support Tezos:


| Wallet                                                                | Developer                                             | Mobile | Web Browser | Tezos only                      | About                                                                                                                                                                               |
| --------------------------------------------------------------------- | ----------------------------------------------------- | ------ | ----------- | ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Kukai](https://wallet.kukai.app)                                     | Kukai                                                 | Yes    | Yes         | Yes                             | A web and mobile based wallet. You can use your Google account or social login to create an account.                                                                                |
| [Temple](https://www.templewallet.com)                                | [Madfish](https://mad.fish)                           | Yes    | Yes         | Tezos, EVM-style chains.        | A browser extension that works on Chrome and Edge. It offers flexible Tezos experience with asset swapping. Recently included EVM support for Etherlink and other EVM-style chains. |
| [Umami](https://www.umamiwallet.com)                                  | [Trilitech](https://www.trili.tech)                   | Yes    | Yes         | Tezos, BTC and EVM-style chains | Originally an electron wallet running on the desktop, Umami has evolved into a multi-chain mobile and web wallet.                                                                   |
| [AirGap](https://airgap.it)                                           | [Papers](https://papers.ch)                           | Yes    | No          | Multi-asset                     | A mobile wallet with the facility to hold the key in a second mobile, hence using an "Air Gap" security model.                                                                      |
| [Ledger Wallet](https://shop.ledger.com/pages/ledger-wallet-download) | [Ledger](https://www.ledger.com)                      | Yes    | No          | Multi-asset                     | The desktop and mobile software to work with the Ledger hardware security module. You can use the Ledger with other Tezos wallets, once setup.                                      |
| `octez-client`                                                        | [Nomadic Labs](https://www.nomadic-labs.com) *et al.* | No     | No          | Yes                             | A command-line wallet typically used on Linux or Mac. It is part of [Octez,](https://octez.tezos.com/) the Tezos blockchain software.                                               |

The `octez-client` command is typically used by developers and infrastructure users. The other wallets run in the web browser or as browser extensions. This means they integrate very well with dApps because everything runs in the same web browser.s
