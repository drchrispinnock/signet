# Preface

[Tezos](https://tezos.com/) is an environmentally friendly proof-of-stake blockchain with on-chain governance. [Signet](https://signetwallet.org) is an open source wallet application for Tezos available for the Mac. It's been written entirely with AI tools. In fact, as I type this preface (into an application I've also written with AI), I haven't written or read a single line of code. Some of my colleagues might say that this is a good thing.

A blockchain wallet is the user's interface to the blockchain. It is where they store their cryptographic keys. These keys represent their accounts on the blockchain. The wallet is also where they sign operations. But it can be more. It can display information about the user's balances and their assets. It can help the user participate in the on-chain governance.

Signet has been in development since 5th October 2026, but it can already do most things a wallet should, particularly on the layer 1. 

In this book, we will tell you about Tezos and how to use the Signet wallet to interact with it. By the end of the book you will have set up an account, be able to send and receive coins, and be able to interact with distributed apps too. You'll be able to buy and sell artwork on NFT sites. Also you'll be able to buy and sell other assets on the chain.

You will need a Mac computer and some patience. Buying cryptocurrency for the first time can take a few days due to cooling off rules. It depends where you live of course. But you can practice on the test networks. It's better to make mistakes on the test networks where the coins have no value, than on *Mainnet* where the coins do. 

I wish you luck in your journey on Tezos and on blockchain generally.
