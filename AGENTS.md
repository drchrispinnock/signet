# Repository guidance

Signet is a native macOS Tezos wallet using SwiftUI, Swift 6, and a Taquito
JavaScript bundle hosted in JavaScriptCore. Read `CLAUDE.md` for detailed
architecture and implementation notes. Before changing the UI, read
`spec/SPEC.md` and inspect `spec/EXAMPLE.png`; consult `spec/ROADMAP.md` for
planned work.

## Layout and conventions

- `Signet/Models`: plain `Sendable` value types and Tezos encoding.
- `Signet/Services`: chain access, wallet persistence, key generation, and
  JavaScriptCore integration. Put new chain data sources behind `ChainService`.
- `Signet/ViewModels`: `@MainActor @Observable` state and user actions.
- `Signet/Views`: SwiftUI views; keep UI work on the main actor.
- `SignetTests`: Swift Testing suites (`import Testing`, `@Test`, `#expect`),
  rather than XCTest.
- `TaquitoBridge/src`: JavaScript bridge and JavaScriptCore polyfills.

Keep Swift 6 complete strict concurrency enabled and new cross-actor types
`Sendable`. Preserve octez-client wallet compatibility, atomic file replacement,
and wallet locking. Never log secret keys or use real wallet files for tests.
Prefer native Swift key handling; the current transfer implementation passes a
secret to Taquito for signing, so review changes to this boundary carefully.

## Build and validation

The Xcode project is generated by XcodeGen. Edit `project.yml`, not
`Signet.xcodeproj/project.pbxproj`, then regenerate:

```sh
xcodegen generate
xcodebuild -project Signet.xcodeproj -scheme Signet -destination 'platform=macOS' -derivedDataPath build build
xcodebuild -project Signet.xcodeproj -scheme Signet -destination 'platform=macOS' -derivedDataPath build test
```

For a targeted test, append
`-only-testing:SignetTests/AddressTests/shortensLongAddresses` (or another suite
or test) to the test command. Run validation appropriate to the change; report
any checks that could not run.

After changing bridge sources or dependencies, rebuild the committed app resource:

```sh
cd TaquitoBridge
npm install
npm run build
```

The output is `Signet/Resources/taquito-bridge.js`; do not hand-edit it.
JavaScript promise callbacks must use `invokeMethod("then", ...)`, rather than
a bare `then.call`, to avoid hanging Swift continuations.

## Persistence and releases

Wallets default to `~/.signet` using octez-client files; app state lives in that
directory's `state` file. Directory, backup, and appearance preferences use
UserDefaults. Tests should use isolated temporary directories.

Version stamping is handled by `scripts/stamp-version.sh` from git tags.
`scripts/release.sh [version]` builds a release archive; pushing a `v*` tag
triggers the GitHub release workflow. Do not publish or push release tags unless
requested.

Preserve unrelated working-tree changes. Keep changes focused and include
generated artifacts when their source changes require regeneration.
